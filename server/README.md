# خادم رفيق: العقل المشترك

هذا هو المساعد التنفيذي الشخصي الذي يعمل على مدار الساعة. يحفظ مهامك وتذكيراتك وذاكرتك ومشاريعك. تتواصل معه من تيليجرام، ومن لوحة تحكم عربية، ومن تطبيق رفيق على الجوال. ويعمل على جوال أندرويد عبر Termux، أو على أي خادم.

> المشروع مستلهم من أفكار [Hermes Agent](https://github.com/NousResearch/hermes-agent)، مثل الذاكرة المنظمة والمجدول وبوابة الرسائل ونظام الأدوات. لكنه مشروع مستقل، ولا يستخدم شيفرة Hermes ولا هويته.

## البنية

```
 تيليجرام ─┐                                       ┌─ Gemini / OpenAI / Claude / OpenRouter / أي خدمة متوافقة
 لوحة التحكم ┼─▶  الوكيل (Agent)  ─▶  طبقة الذكاء الاصطناعي  ┤   (+ مزوّد احتياطي وإعادة محاولة)
 تطبيق الجوال ┘      │                                  └─ تحويل الصوت ↔ نص
                    ▼
            سجل الأدوات (34 أداة)  ── مستويات موافقة: 1 تلقائي · 2 بموافقة · 3 محظور
                    │
       ┌────────────┼──────────────┬─────────────┐
     SQLite (WAL)  المجدول الدائم   الملفات      سجل العمليات
     + بحث FTS5    (يُستأنف بعد      (مجلد لكل     والتكلفة
                   أي انقطاع)        مستخدم)
```

| الطبقة | التقنية | سبب الاختيار |
|---|---|---|
| الخادم | Python 3.11+ مع Starlette وUvicorn | مكتبات Python خالصة، فتُثبَّت على Termux بلا مترجم، واستهلاكها للذاكرة قليل (نحو 60 ميجابايت). |
| قاعدة البيانات | SQLite بوضع WAL مع FTS5 | ملف واحد موثوق، لا يحتاج خادمًا منفصلًا، ونسخه الاحتياطي سهل. PostgreSQL وRedis زائدان عن الحاجة لمستخدم واحد على جوال. |
| المجدول | جدول `jobs` في قاعدة البيانات | يبقى بعد إعادة التشغيل، ولكل مهمة مفتاح فريد يمنع تنفيذها مرتين، وفيه إعادة محاولة متدرجة. |
| تيليجرام | استطلاع طويل (long polling) | لا يحتاج عنوانًا عامًا ولا HTTPS، فيناسب الجوال. |

## التثبيت على الجوال (Termux): دليل المبتدئ

1. ثبّت **Termux** و**Termux:Boot** من متجر [F-Droid](https://f-droid.org/packages/com.termux/). نسخة Google Play قديمة ولا تعمل.
2. افتح Termux والصق هذا الأمر:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/al-hiraf/Alharith_ai/main/server/install-termux.sh | bash
   ```
3. سيطلب منك مفتاح Gemini ورمز بوت تيليجرام، ويمكنك تركهما فارغين وإضافتهما لاحقًا.
4. افتح المتصفح على الجوال وادخل إلى **http://127.0.0.1:8787**، ثم أنشئ حساب المدير.
5. **ليعمل على مدار الساعة:**
   - افتح Termux:Boot مرة واحدة.
   - اجعل البطارية «غير مقيّدة» لتطبيقَي Termux وTermux:Boot.
   - اترك الجوال على الشاحن.

### ربط تيليجرام
1. في تيليجرام افتح [@BotFather](https://t.me/BotFather)، وأرسل `/newbot`، ثم انسخ الرمز.
2. ضع الرمز في ملف `.env` في السطر `TELEGRAM_BOT_TOKEN=`، ثم أعد التشغيل بالأمر `sv restart rafiq`.
3. في لوحة التحكم ادخل إلى **الإعدادات ← ربط تيليجرام**. ستحصل على رمز من 6 أرقام صالح لمدة 10 دقائق.
4. أرسل إلى البوت: `/link 123456`.

أي حساب تيليجرام لم يُربط بهذه الطريقة يُرفض.

### ربط تطبيق رفيق (العقل المشترك)
1. في لوحة التحكم ادخل إلى **الإعدادات ← إنشاء مفتاح وصول**، وانسخ المفتاح.
2. في التطبيق ادخل إلى **الإعدادات ← العقل المشترك**:
   - العنوان: `http://127.0.0.1:8787`.
   - الصق المفتاح.

بعدها تصبح المهام والذاكرة والتذكيرات التي تنشئها من التطبيق نفسها التي في تيليجرام واللوحة.

### الأوامر المفيدة
```bash
sv status rafiq                 # الحالة
sv restart rafiq                # إعادة التشغيل بعد تعديل .env
tail -f ~/rafiq/server/data/logs/current     # السجلات
cd ~/rafiq/server && .venv/bin/python -m harith check      # فحص الإعدادات واختبار الاتصال بالذكاء الاصطناعي
.venv/bin/python -m harith backup                              # نسخة احتياطية الآن
sv down rafiq && .venv/bin/python -m harith restore NAME.db && sv up rafiq   # استعادة نسخة
.venv/bin/python -m harith pause   /   resume                  # إيقاف طارئ من الطرفية
```

### الوصول من الحاسوب (اختياري)
اللوحة مقيّدة افتراضيًا بالجوال نفسه (`127.0.0.1`). للوصول إليها من الخارج **لا تفتح المنفذ مباشرة**، واستخدم نفقًا مشفّرًا:
```bash
pkg install cloudflared
cloudflared tunnel --url http://127.0.0.1:8787
```
ستحصل على رابط `https://….trycloudflare.com`. اللوحة محمية بكلمة مرور، وبحد لمحاولات الدخول، وبحماية من هجمات CSRF.

### على خادم VPS بدل الجوال
```bash
git clone https://github.com/al-hiraf/Alharith_ai && cd Alharith_ai/server
cp .env.example .env && nano .env
docker compose up -d
```
ضع أمامه Caddy أو Nginx مع HTTPS.

## توزيع رفيق على مستخدمين آخرين (بلا إعداد)

كل من يثبّت التطبيق يضغط «ابدأ فورًا» في شاشة الترحيب، فيأخذ جهازه مفتاحًا فرعيًا من حسابك في OpenRouter بحد شهري (افتراضيًا 5$). لا يحتاج المستخدم أي مفتاح أو حساب.

**الطريقة المجانية (من جوالك، بلا نطاق):**
1. أنشئ **مفتاح إدارة** من openrouter.ai ← Settings ← Provisioning keys.
2. أنشئ **مفتاح GitHub** من github.com ← Settings ← Developer settings ← Fine-grained tokens:
   - المستودع: Alharith_ai فقط.
   - الصلاحية: Contents: Read and write.
3. شغّل أمر التثبيت في Termux، وأجب **y** على سؤال التوزيع، والصق المفتاحين.
4. انتهى. هذا ما يحدث تلقائيًا بعدها:
   - الجوال يشغّل نفق Cloudflare مجانيًا (رابط `https://….trycloudflare.com`).
   - عند كل تشغيل ينشر الخادم الرابط الجديد في فرع `server-url` على GitHub.
   - تطبيق رفيق يقرأ الرابط من هناك، فيظهر لكل مستخدم زر «ابدأ فورًا».
5. تتابع المستخدمين من لوحة التحكم ← **مستخدمو التطبيق**: استهلاك كل واحد هذا الشهر، وتعديل حده، وإيقافه، وإلغاء مفتاحه.

التسجيل يحتاج الخادم شغالًا لحظة الضغط على «ابدأ فورًا» فقط. بعدها يعمل التطبيق مباشرة مع OpenRouter حتى لو أُطفئ جوالك.

**برابط ثابت (اختياري):** على VPS أو بنطاق خاص، ضع الرابط في GitHub ← Settings ← Variables باسم `RAFIQ_SERVER_URL`.

**الحماية:**
- مفتاح الإدارة لا يغادر الخادم.
- المفتاح الفرعي يُرسل للجهاز مرة واحدة عبر HTTPS ولا يُخزَّن في الخادم.
- التسجيل محدود بخمس مرات في الساعة لكل عنوان IP، وبعدد أقصى من المستخدمين.
- يمكن اشتراط رمز دعوة (`PROVISION_INVITE_CODE`).
- إعادة تثبيت التطبيق تلغي المفتاح القديم تلقائيًا.

**تنبيه:** المحادثة الصوتية المباشرة تحتاج مفتاح Gemini خاصًا بالمستخدم، لأن OpenRouter لا يدعمها. الأوامر العادية والمحادثة بالكتابة والصوت العادي تعمل كلها بالمفتاح الفرعي.

## الأعمال والمالية (الشركات، الفواتير، العملاء، الاجتماعات)

كل شيء متاح بالصوت أو الكتابة (التطبيق، تيليجرام) ومن لوحة التحكم:

| الوحدة | ماذا تفعل |
|---|---|
| **الشركات** | مساحة مستقلة لكل شركة أو نشاط، بعملتها ونسبة ضريبتها. المساحة الشخصية منفصلة تمامًا، ولا تُخلط أموال جهة بأخرى. لكل جهة: المشاريع وميزانياتها، مؤشرات KPI، المخاطر، الاجتماعات، وسجل التعديلات. |
| **المالية** | دخل ومصروفات، ميزانية لكل بند (مع تنبيه عند 80٪ وعند التجاوز)، التزامات شهرية متكررة، تدفق نقدي، مستحقات لك وعليك، وتوقع بسيط مع افتراضاته. |
| **الفواتير والعروض** | فاتورة لعميل، عرض سعر، فاتورة مورد. الضريبة تُحسب تلقائيًا، والترقيم آلي (INV/QT/BILL). تحويل العرض المقبول لفاتورة، تسجيل الدفعات الجزئية، ومستند A4 عربي للطباعة أو الحفظ PDF. |
| **العملاء والموردون** | عملاء، عملاء محتملون بمراحل البيع، موردون، شركاء، موظفون (مع تاريخ انتهاء العقد). يظهر لكل عميل ما عليه. |
| **الاجتماعات** | جدول أعمال وتذكير قبل الموعد. المحضر يتحول إلى مهام فعلية بمسؤول وموعد، والقرارات تُسجَّل في المشروع. |
| **التصدير** | Excel ‏(.xlsx) أو CSV أو صفحة طباعة/PDF: القيود، الفواتير، جهات الاتصال، التقرير المالي، المهام. |
| **التنبيهات** | كل صباح الساعة 8: التزام يستحق اليوم، فاتورة تأخرت، عقد ينتهي بعد 30 أو 7 أيام أو يوم واحد. |
| **البحث الشامل** | بحث واحد في المهام والمشاريع والجهات والفواتير والقيود والاجتماعات والذاكرة والملفات. |

أمثلة: «سجل مصروف بنزين ٢٥٠»، «استلمت ٥٠ ألف من النخبة على فاتورة ٣»، «اعمل عرض سعر لأبو خالد: هدم ٣٥٠٠ وبلك ٤٢ متر بـ٩٥»، «كم صرفنا على المواد هذا الشهر في المؤسسة؟»، «صدّر تقرير الشهر Excel».

حدود ثابتة:
- الأرقام من تسجيلك فقط. لا ربط بنكي، ولا أرصدة مخترعة، ولا تحويل بين العملات.
- التسجيل ليس دفعًا: رفيق لا يحوّل أموالًا ولا يدفع شيئًا.
- الفواتير مسودات ترسلها أنت. هي ليست فواتير إلكترونية معتمدة لدى هيئة الزكاة والضريبة والجمارك (فاتورة).
- حذف قيد مالي يحتاج موافقتك.
- بيانات الموظفين للمراجعة البشرية فقط، ولا قرارات توظيف أو فصل آلية.

## الأمان

- **الأسرار** تُحفظ في `.env` فقط، بصلاحية 600. لا تُرسل إلى الواجهة، وتُخفى تلقائيًا من السجلات. الذاكرة ترفض حفظ كلمات المرور والمفاتيح وأرقام البطاقات.
- **المصادقة:**
  - كلمات المرور مشفرة بـ PBKDF2-SHA256 (200 ألف دورة).
  - الجلسات في كوكي HttpOnly وSameSite=Strict.
  - الطلبات المعدِّلة تتطلب ترويسة `X-Harith`، وهذه حماية من CSRF.
  - مفاتيح التطبيق مخزنة كبصمة (hash).
- **مستويات الموافقة:**
  - **المستوى 1 (تلقائي):** تنظيم المهام والملاحظات، القراءة، التلخيص، البحث.
  - **المستوى 2 (بموافقتك):** إرسال البريد. تصلك أزرار موافقة أو رفض في تيليجرام واللوحة، والموافقة تُنفّذ مرة واحدة فقط.
  - **المستوى 3 (محظور على المساعد):** الحذف النهائي للملفات، والتحويلات المالية، وتوقيع العقود، والإقرارات الرسمية. يجهّز المساعد مسودة فقط.
- **حقن التعليمات:**
  - محتوى صفحات الويب والملفات يُغلَّف كـ«محتوى خارجي غير موثوق»، ولا يستطيع إغلاق الغلاف.
  - الوكيل مُوجَّه بألا ينفذ ما بداخله.
  - روابط الشبكة الداخلية محظورة لمنع هجمات SSRF.
- **الإيقاف الطارئ:** زر في اللوحة، أو `/stop` في تيليجرام، أو `harith pause` في الطرفية. يوقف الطلبات الجارية فورًا ويمنع أي أداة من العمل.
- **حد التكلفة اليومي:** يتوقف المساعد عند بلوغه، وقيمته الافتراضية 2$.
- **فصل المستخدمين:** كل استعلام مقيّد بـ `user_id`، ولكل مستخدم مجلد ملفات خاص.
